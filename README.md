# make-knowledge-cards

把一篇文章提炼成 **5~8 张知识卡片**的开源 Skill。每张卡片只讲一个知识点，包含：标题、核心知识、简明解释、例子或自测问题。适合把长文、教程、读书笔记快速变成可复习的闪卡。

## 解决什么问题

读完一篇长文后，常见的痛点是：当时觉得懂了，过几天就忘；想复习却还要重新读一遍全文；手动做笔记又容易抄成缩写版、抓不住重点。

这个 Skill 解决的就是"读完难复习"的问题——把一篇文章自动压缩成少量、原子、可自测的卡片，让你花几分钟就能回忆起原文的关键论点，而不是重新通读全文。它只做这件事：输入文章正文，输出 Markdown 知识卡片。

## 主要功能

- **一卡一点**：每张卡片只讲一个知识点，自动合并跨段落重复的论点、删除重复内容。
- **忠于原文**：卡片中的事实、数字、结论都必须能在原文中找到依据，不编造原文没有的案例或数据。
- **数量自适应**：目标 5~8 张；原文信息量不足时不硬凑，按实际独立知识点输出并说明。
- **两种输入**：直接粘贴正文，或给出本地 `.md` / `.txt` 文件路径。
- **语言跟随原文**：中文文章出中文卡片，英文文章出英文卡片。
- **每张卡片四要素**：标题 / 核心知识 / 简明解释 / 例子或自测问题。

**暂不支持**（明确边界，避免误用）：网页与 URL 抓取、PDF/Word/图片格式、Anki `.apkg` 导出、图形界面或可视化卡片窗口——只输出 Markdown 文本。

## 安装方法

这是一个纯指令型 Skill（只有 `SKILL.md` 与代理元数据，无可执行脚本、无运行时依赖），安装即"把目录放进 Skill 加载路径"：

1. 把整个 `skills/make-knowledge-cards/` 目录复制到你所用 Agent 的 Skill 目录下（例如 `.user_skills/` 或等价的 skills 加载目录）。
2. 重启或重新加载 Agent，使其识别新 Skill。
3. （可选）用官方 `quick_validate.py` 指向本 Skill 目录做一次结构校验，输出 `Skill is valid!` 即表示 frontmatter 与命名规范通过。

## 使用方法

1. 准备文章，二选一：
   - 直接把正文粘贴到对话中；
   - 把文章存为 `.md` 或 `.txt`，并在对话中给出文件路径。
2. 说一句触发语，例如：
   - "把这篇文章整理成知识卡片"
   - "根据 `notes.md` 生成 5~8 张复习卡片"
3. Agent 会按 `SKILL.md` 中的流程（通读 → 抽点 → 去重 → 筛选 → 填字段）输出 Markdown 卡片。

## 输入输出示例

**输入**（粘贴正文）：

```
把下面这篇文章做成知识卡片：

一个"番茄钟"的标准流程是：选定一项任务，设定 25 分钟倒计时；
这 25 分钟里只做这件事，不回消息、不切任务；铃响后休息 5 分钟，
并在纸上画一个叉。每完成 4 个番茄钟，安排一次 15~30 分钟长休息。
中途冒出的临时念头先记在旁边的"外清单"上，结束再处理，不要立刻切任务。
```

**输出**（原文较短，只提炼出 3 个独立知识点，不硬凑到 5 张）：

```
已根据《番茄工作法》生成 3 张知识卡片。

### 卡片 1：一个番茄钟的标准结构
- **核心知识**：25 分钟专注一件事 + 5 分钟休息；每 4 个番茄钟安排一次长休息。
- **简明解释**：启动倒计时后只做当前任务，铃响休息并在纸上记一个叉。
- **例子 / 自测**：自测——连续做完 4 个 25 分钟后应该做什么？

### 卡片 2：用"外清单"接住被打断的念头
- **核心知识**：中途冒出的临时念头先记下来，等番茄钟结束再处理。
- **简明解释**：立刻切任务会打断专注；记下来既不丢失，又保住当前这一段。
- **例子 / 自测**：自测——工作中突然想回一条消息，正确做法是？

### 卡片 3：长休息的节奏
- **核心知识**：每完成 4 个番茄钟，休息 15~30 分钟。
- **简明解释**：短冲刺之后需要更长恢复，而不是继续连轴转。
- **例子 / 自测**：自测——长休息发生在每完成几个番茄钟之后？
```
