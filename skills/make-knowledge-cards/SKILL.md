# Make Knowledge Cards

## 概述

把一篇文章压缩成少量、原子、可复习的知识卡片。目标是让用户读完卡片就能回忆原文的关键论点，而不是得到一份缩写版摘要。

## 输入与边界

接受的输入：

- 用户在对话中直接粘贴的正文。
- 用户给出的本地 `.md` / `.txt` 文件路径：用读取文件的工具完整读入后再处理。

拒绝并说明原因的输入：

- 网页/URL 链接：本 Skill 不抓取网页。请用户复制正文粘贴，或另存为 `.md`/`.txt` 后再提供路径。
- PDF、Word、图片等其他格式：不在支持范围内，请用户先导出为纯文本。
- 用户要求导出 `.apkg`/Anki 牌组、或要求弹出窗口/可视化卡片：不支持，只输出 Markdown 文本。

## 工作流程

1. **先完整读入原文**。不要边读边抽点；先通读，建立全文理解，再动手。
2. **列出候选知识点**。从原文中找出承载真正信息的原子点：核心概念、关键结论、因果关系、重要步骤、数据/规则、对比关系。跳过铺垫、寒暄、重复举例和过渡句。
3. **去重与合并**。同一意思在不同段落出现只保留一张；把跨段落散落的同一论点合并到一张卡片。
4. **筛选 5~8 张**。只保留最有复习价值的点，按原文逻辑顺序排列。原文很短或信息稀疏时，**宁可少做也不要凑数**——可以只出 3~4 张，并在开头注明"原文信息量有限，仅提炼出 N 个独立知识点"。
5. **逐张填写四个字段**（见下）。
6. **输出前自检**：每条陈述能否在原文中找到依据？是否一张卡片只讲一件事？有没有重复？

## 卡片规范

每张卡片只讲**一个**知识点，包含四个字段：

- **标题**：1 行，点出这个知识点是什么，不超过约 20 字。
- **核心知识**：1~2 句话给出最该记住的结论或定义。
- **简明解释**：2~4 句话展开：它为什么成立、和相关概念有何区别、或关键机制是什么。
- **例子 / 自测**：二选一——要么用原文中的一个小例子佐证，要么出一道能由本卡片回答的自测题（问句形式，答案即卡片内容）。不要新造原文之外的事实。

## 输出格式

用 Markdown 输出，结构如下：

```
已根据《{原文标题或首句概括}》生成 {N} 张知识卡片。

### 卡片 1：{标题}
- **核心知识**：……
- **简明解释**：……
- **例子 / 自测**：……

### 卡片 2：{标题}
……
```

要求：

- 卡片编号连续，从 1 开始。
- 输出语言与原文一致（中文文章出中文卡片，英文文章出英文卡片）。
- 不要输出多余的寒暄、"希望对你有帮助"之类的套话；若信息量不足而少于 5 张，在开头一句说明即可。
- 不要改写、润色或补写原文没有的背景；不确定的内容宁可不写。

## 质量红线

- **不编造**：四个字段中的每一条事实、数字、结论都必须能在原文中找到依据。不得补充原文未提及的案例、数据或权威观点。
- **一卡一点**：一张卡片不得同时讲两个并列概念；发现讲了两件事就拆开。
- **去重**：禁止两张卡片的核心知识在说同一件事。
- **不凑数**：独立知识点不足 5 个时按实际数量输出。
- **忠于原文立场**：复述作者观点时不夹带自己的评价或修正。

## 示例

输入原文（节选自一篇讲"刻意练习"的文章）后，输出形如：

```
已根据《刻意练习》生成 6 张知识卡片。

### 卡片 1：刻意练习不等于重复做熟悉的事
- **核心知识**：刻意练习的关键是走出舒适区，在略高于当前水平的难度上持续练习。
- **简明解释**：单纯重复已经掌握的动作不会带来进步；只有当任务稍微超出能力、并伴随反馈时，大脑才会重构技能。
- **例子 / 自测**：自测——为什么天天开车开十年也不会变成赛车手？因为动作已进入自动化，不再处于"学习区"。

### 卡片 2：反馈是刻意练习的必要环节
- **核心知识**：没有及时反馈的练习，很容易把错误固化下来。
- **简明解释**：练习后需要有人或有机制指出哪里错了，才能针对性修正；闭门苦练可能只是在巩固坏习惯。
- **例子 / 自测**：自测——练习后立刻知道对不对，属于哪个要素？
```
